# Exercises and Solutions Roadmap

## Beginner

1. Formulate a 0-1 selection problem.
2. Add a budget.
3. Add dependencies.
4. Add mutual exclusion.
5. Solve a small knapsack by hand.
6. Compare LP and ILP.

## Intermediate

7. Assignment with eligibility constraints.
8. Facility location with fixed charges.
9. Production planning with integer batches.
10. Capital budgeting.
11. Set covering.
12. Set partitioning.

## Advanced

13. Multi-period production/inventory.
14. Workforce scheduling.
15. Vehicle-routing-inspired assignment model.
16. Robust/scenario-based facility location.
17. Decomposition intuition.
18. Compare formulations of the same scheduling problem.

## Challenge

Implement a tiny branch-and-bound MILP solver for binary variables using:
- LP relaxation;
- branching;
- incumbent;
- bound;
- pruning.

Then compare it with HiGHS on small instances.
